# QR Builder

A clean, fast, and professional **QR Code Generator** built with **HTML, CSS, and JavaScript**. Easily generate and customize QR codes with a modern, responsive interface.

## 🚀 Live Demo

🌐 **[Open QR Builder](https://karthikj-2008.github.io/QR-code-Generator/)**

## ✨ Features

- ⚡ **Instant QR Code Generation** – Just type and generate.
- 🎨 **Custom Colors** – Choose from 5 beautiful QR code colors.
- 📥 **Download as PNG** – Download your QR code with one click.
- 📱 **Fully Responsive** – Works smoothly on mobile and desktop.
- 💻 **No Backend Required** – Runs directly in your browser.
- ✨ **Modern & Minimal UI** – Clean and professional design.

## 🛠️ Technologies Used

- **HTML5** – Webpage structure
- **CSS3 & Tailwind CSS** – Styling and responsive design
- **JavaScript** – QR code generation and functionality
- **QRCode.js** – QR code generation library
- **Font Awesome** – Icons
